# docs/ — portada y galería

Las imágenes publicadas del proyecto. Acá no hay código: es el resultado de correr
los pósteres y las animaciones.

- [`FLUJOS.md`](./FLUJOS.md) — el catálogo de todos los flujos: descarga, póster,
  cuadros, animación y qué se verificó.
- `portada.png` — el póster de disco completo (GOES-East C13, paleta `ir_realce`)
  que ilustra el README.
- `galeria/` — el resto de los PNG: pósteres de disco, vistas regionales, el globo
  centrado en Paraguay y las anomalías de temperatura de ERA5.
  - `mur_sst_globo_2025-01-01.png` — el globo de MUR (anomalía de SST semanal).
  - `truecolor_noaa20_globo_2024-09-28.png` — el globo de True Color (VIIRS NOAA-20).
  - `himawari_b13_globo_2026-10-21T2020.png` — Himawari-9 AHI B13 (ciclon del mar Filipino).
  - `sandwich_globo_G19_2026-10-04T1800.png` — Sandwich RGB de GOES-19.
  - `precip_globo_ecmwf_2026-10-20_06z_fh144.png` — precipitación acumulada IFS.
  - `precip_aifs_ens_globo_2026-10-20_12z_fh360.png` — ensamble AIFS-ENS.
  - `anomalia_2t_ifs_globo_2026-10-20_12z_fh360.png` — anomalía de 2 m del IFS.
  - `viento_250_globo_2026-10-20_18z_fh144.png` — viento en 250 mb y MSLP.

  - `goes_truecolor_globo_2026-10-24T1950.png` — color real de GOES-19 (C01 + C02 + C03).
